## データ構成

制作するサイトデータの構成です。
各ページのコンテンツをBlock要素で構成するという特徴があります。

| 名前       | 説明                                                                   | ディレクトリ     |
| ---------- | ---------------------------------------------------------------------- | ---------------- |
| Pages      | 各ページのデータです。Astroの標準機能を使用します。                    | /src/pages/      |
| Layouts    | ページのレイアウトデータです。全ページで何かしらのLayoutを使用します。 | /src/layouts/    |
| Blocks     | 各ページを構成する要素です。Blockを組み合わせてページを制作します。    | /src/blocks/     |
| Components | LayoutsやBlocks内で使用する再利用可能なパーツです。                    | /src/components/ |
| Data       | サイトに必要なデータを管理します。                                     | /src/data/       |

```plaintext
/
├── dist      ...buildしたデータ
├── public    ...画像データ（public画像）などの静的アセッツ
├── scripts   ...開発に必要なnode.jsのコード
├── src       ...開発データ
│ ├── blocks      ...ブロックデータ
│ ├── components  ...部品データ
│ ├── data        ...案件に関わるデータ
│ ├── icons       ...アイコン用のsvgデータ
│ ├── image       ...画像データ（src画像）
│ ├── layouts     ...各ページで使用するレイアウト
│ ├── pages       ...各ページのデータ
│ ├── script      ...コンポーネントに依存しないスクリプト
│ ├── styles      ...共通スタイル
│ └── types       ...型データ
└── tokens    ...デザイントークンファイル
```
